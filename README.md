# iCRUD — Sistema de Gerenciamento de Estoque

## Projeto e integrantes

O **iCRUD** é um sistema de gerenciamento de estoque de alimentos voltado para restaurantes. O sistema tem como objetivo facilitar o controle dos produtos armazenados, permitindo acompanhar os itens disponíveis, suas quantidades e informações relevantes para a gestão do estoque.

O projeto busca resolver problemas comuns no controle manual de estoque, como falta de organização, dificuldade para acompanhar a quantidade de produtos e risco de perda de alimentos.
